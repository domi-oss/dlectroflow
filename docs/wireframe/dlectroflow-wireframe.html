Screen notes — Inbox (source: inbox-view.tsx)

  • Capture bar is the single required interaction — zero-friction capture, autofocus on load, "/" key refocuses it from anywhere. On Enter the item saves with a quick "captured ✓" inline confirmation (no modal, no blocking).
  • Freshness scale (Task Snacking): every unsorted item ages through 🟢 Fresh → 🟡 Softening (4h) → 🟠 Soggy (8h) → 🔴 Stale (12h) — in Plain voice: Recent → Aging → Overdue → Way overdue. It's a no-guilt nudge, not a deadline. Rows sort freshest/newest first.
  • Freshness is a gentle nudge only — no penalty. Once an item's gone untouched 24h, the row surfaces a "still needed?" check with a Dismiss to clear the prompt.
  • 24h review prompt: once an item's gone untouched for 24h it surfaces an inline "still needed?" check — a light forced decision, never an auto-delete. A daily review nudge batches these up (candidate for a real scheduled reminder).
  • Each row's actions: Snack-size it / Break into steps (→ Breakdown), Add to-do (skip breakdown → the To do / Quick bites bucket), Save for later (→ the Saved for later / Pantry bucket, freshness paused), and a red 🗑️ Delete icon.
  • Pantry / Saved for later holds "later" items with the freshness clock paused; Quick bites / To do holds single items committed without a breakdown.
  • Sorted section: broken-down tasks in progress, grayed to recede, each showing step progress (e.g. "2/5 done"; gray "· not scheduled"). Fully finished tasks graduate to the Library's Done tab. Whole row reopens its confirmed breakdown.
  • Voice toggle: all wording above flips between Plain and Playful via the top-bar switch or Settings. Same data, same features.

Screen notes — Breakdown / Task page (source: breakdown-chat.tsx)

  • Claude streams a proposal as chat text and a structured, directly-editable step list — emoji, text, and a per-step estimated time to spend (highlighted amber, tap ✏️ to edit) — simultaneously.
  • Quick-reply chips (More bites/steps · Fewer bites/steps) plus free-text let the user redirect Claude without leaving the flow.
  • Per-step controls: Back to the kitchen / Back to inbox ejects a too-big step out to the Inbox as its own item to re-break-down; 🗑️ removes it. Confirm the whole set, after which steps become read-only.
  • Confirmation state branches on integration status: Google Tasks configured → connect/send; else Reclaim MCP → connect/send. Both are optional — steps always save locally regardless.
  • This same route is what a Sorted item opens — not a different screen, just this page rendered in one of two confirmed states depending on whether scheduling actually succeeded. Use the toggle to preview all three.
  • Start focusing / Dig in (both confirmed states) navigates into the Focus Timer's setup state, completing the schedule→focus handoff.

Screen notes — Focus Timer (source: focus-timer.tsx)

  • Circular SVG progress ring is the focal element — countdown is the whole point of this screen, minimal chrome around it.
  • Snack vocabulary (Playful voice): a task is the "snack", each step is a "bite" (header reads "bite 2 of 4"); Plain voice keeps "step 2 of 4".
  • "Time's up" doesn't auto-fail: offers Yes done, add more time, or re-estimate (Claude proposes a kinder new estimate).
  • Completion screen shows a celebration, points/crumbs, and streak status — explicitly designed for dopamine payoff (ADHD-focused UX).
  • Pause for now is a first-class, low-shame exit — it ends the session, keeps the step in its task (not lost), and surfaces a "focus step paused — resume" banner in the Inbox. Lands on a quieter no-confetti card; never buried, never a failure.
  • Persistent top row (← Back to steps + four state buttons) mirrors the Breakdown pattern; four clickable sub-states (Setup / Running / Time's up / Done) are wired the way the real state machine flows.

Screen notes — Settings (new)

  • App voice is the headline setting: a live Plain/Playful toggle. Plain is the default so the app is safe to screen-share and lowers the barrier for users the playful voice might put off; Playful keeps the ADHD-friendly, low-shame identity. Flip it here or from the top bar — the whole app rewords instantly (and the choice persists).
  • Freshness thresholds make the 4h/8h/12h tiers configurable; the daily review nudge time + toggle is the home for the "items untouched 24h" prompt (candidate for a real scheduled reminder).
  • Integrations surface Reclaim + Google Tasks connection state — the same connect prompts shown in the Breakdown confirmation.
  • Wireframe-level only: inputs/toggles are illustrative. Freshness-tier labels themselves follow the active voice.

Screen notes — Library (new)

  • One hub for everything that's left your inbox, with four tabs: To do / Quick bites (single action items, no breakdown), Saved for later / Pantry (stored, freshness paused, wake times), Sorted (broken-down tasks in progress, with step progress), and Done (fully finished tasks — a closure pile). Whole rows reopen the breakdown.
  • The Inbox keeps short previews of each bucket with a see all → link that deep-links to the matching tab here, so the Inbox stays focused on capture + review.
  • Plated rows offer Start focusing/Dig in (single-step focus), Done, Break down/Snack-size it (if it turns out to need steps after all), and delete.
  • Fully voice-aware like the rest of the app. Hub name: Library (business) / Larder (snack).

End-to-end flow

🧠 Capture (Inbox)→ ✂️ Clarify (Claude breakdown)→ 📅 Schedule (Reclaim / Google Tasks)→ ⏱️ Focus (Timer)→ 🎉 Reward (Dashboard, streaks)

This wireframe mirrors the actual route structure: /inbox → /tasks/[taskId] (breakdown) → /focus/[stepId] → /dashboard (+ /settings), built from the real components (inbox-view.tsx, breakdown-chat.tsx, focus-timer.tsx) and Prisma schema already in the repo. It's intentionally low-fidelity (dashed borders, gray placeholders) to keep focus on structure and flow. The Business / Snack voice toggle (top bar or Settings) rewords the entire UI live.
